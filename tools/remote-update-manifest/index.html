Questions

What is Remote Update?

An app built with Remote Update on reads a small JSON file you host. Change the file and every installed copy picks up the change on its next launch (and within about 15 seconds while it is open): a new start page, an announcement, maintenance mode, menu text, or new bundled pages. No new release, no store review.

Where do I host the file?

Anywhere that serves a public https URL: your own website, GitHub Pages, Cloudflare Pages, Firebase Hosting or a public storage bucket. Put the same address in the app's Remote Update setting when you build it.

Can the file add ads or change permissions?

No. The app only accepts a fixed list of safe fields. Ads can be tuned or switched off remotely, never switched on; permissions, package name and signing can never change.

What happens if the file is missing or broken?

Nothing changes. A missing, unreachable or invalid file is never treated as an instruction: the app keeps running as it is.
