Informasi Dasar

Beri nama aplikasi Anda, lalu pilih apa yang ditampilkannya: situs web, HTML Anda sendiri, atau ZIP situs Anda

Ini akan tampil di layar utama pengguna (maks 30 karakter)
Situs web yang akan dimuat di aplikasi Anda (harus diawali https://)
Satu halaman, dengan CSS dan JavaScript inline. Dikemas di dalam aplikasi dan berfungsi offline.
Satu halaman .html. Untuk halaman dengan file gambar, CSS, atau JS sendiri, gunakan ZIP.
ZIP dengan index.html (di tingkat atas, dalam satu folder teratas, atau di dist/ atau build/). Semua isinya dikemas di dalam aplikasi dan berfungsi offline. File Anda dikirim ke server build kami hanya untuk membuat aplikasi, dan tidak disimpan.
Aplikasi pengembangan yang menampilkan dev server PC Anda (Vite, Next.js...) sebagai http://localhost:PORT, dengan hot reload. Hubungkan ponsel lewat USB dan jalankan adb reverse tcp:PORT tcp:PORT. Hanya untuk pengujian: buat aplikasi sebenarnya dari situs atau ZIP Anda.
