Questions

Les réponses courtes.

Cherchez dans les guides, la FAQ et les tarifs, ou posez-nous la question.

FreeWebToApk est-il vraiment gratuit ?

Oui. Créer l'APK et l'AAB Google Play sur ce site est gratuit et illimité, sans inscription et sans filigrane de notre part. Le site affiche des publicités pour s'autofinancer ; l'application que vous créez n'affiche aucune publicité de notre part.

Puis-je publier mon application sur Google Play ?

Oui. Chaque compilation vous donne un AAB, le format demandé par Google Play. Un nom de package est toujours signé avec la même clé : lorsque vous le compilez de nouveau plus tard, la nouvelle version s'installe comme une mise à jour. Le guide de publication détaille la fiche.

Que puis-je transformer en application ?

N'importe quelle adresse de site web, un ZIP de votre site avec un index.html (pour React ou Vite, compressez le dossier dist compilé), un seul fichier HTML ou du HTML collé. Cela couvre WordPress, Shopify, Wix, Webflow et les applications créées avec Lovable, Bolt, v0, Replit et des outils similaires.

Le code que j'importe est-il protégé dans l'application ?

Les pages que vous intégrez depuis un ZIP ou du HTML sont chiffrées dans l'APK et l'AAB : ouvrir le fichier comme un ZIP affiche des données brouillées au lieu de votre code. Cela empêche la copie occasionnelle ; comme toute application qui doit exécuter son propre code, ce n'est pas incassable.

Dois-je installer quelque chose ?

Non. Vous créez l'application directement ici, sur le site web, sans rien installer. L'application Android AppMint est facultative et ajoute le générateur d'applications IA ainsi que les applications de documents, d'audio, de vidéo et d'images.
