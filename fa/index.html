چه چیزی را می‌توانم به اپ تبدیل کنم؟

هر نشانی وب‌سایت، یک ZIP از سایت شما با فایل index.html (برای React یا Vite، پوشهٔ dist ساخته‌شده را زیپ کنید)، یک فایل HTML واحد، یا HTML که جای‌گذاری می‌کنید. این شامل WordPress، Shopify، Wix، Webflow و اپ‌هایی است که با Lovable، Bolt، v0، Replit و سازندگان مشابه ساخته شده‌اند.

آیا کدی که بارگذاری می‌کنم داخل اپ محافظت می‌شود؟

صفحه‌هایی که از ZIP یا HTML بسته‌بندی می‌کنید داخل APK و AAB رمزگذاری می‌شوند، بنابراین باز کردن فایل به‌عنوان ZIP به‌جای کد شما داده‌های درهم‌ریخته نشان می‌دهد. این کار جلوی کپی‌برداری معمولی را می‌گیرد؛ مثل هر اپی که باید کد خودش را اجرا کند، شکست‌ناپذیر نیست.
