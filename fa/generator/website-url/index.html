اطلاعات پایه

برای اپلیکیشنتان نام بگذارید، سپس انتخاب کنید چه نشان دهد: یک وب‌سایت، HTML خودتان یا یک ZIP از سایتتان

این در صفحه اصلی کاربر نمایش داده می‌شود (حداکثر 30 نویسه)
وب‌سایتی که در اپلیکیشن شما بارگذاری می‌شود (باید با https:// شروع شود)
یک صفحه، با CSS و JavaScript درون‌خطی. درون اپلیکیشن قرار می‌گیرد و آفلاین کار می‌کند.
یک صفحه .html تکی. برای صفحه‌ای که تصویر، CSS یا JS جداگانه دارد، ZIP را استفاده کنید.
یک ZIP که index.html دارد (در بالاترین سطح، در یک پوشه سطح بالا یا در dist/ یا build/). همه‌چیز داخل آن درون اپلیکیشن قرار می‌گیرد و آفلاین کار می‌کند. فایل‌های شما فقط برای ساخت اپلیکیشن به سرور ساخت ما فرستاده می‌شوند و نگهداری نمی‌شوند.
یک اپلیکیشن توسعه که سرور توسعه رایانه شما (Vite، Next.js و...) را به‌صورت http://localhost:PORT با hot reload نشان می‌دهد. گوشی را با USB وصل کنید و adb reverse tcp:PORT tcp:PORT را اجرا کنید. فقط برای آزمایش: اپلیکیشن واقعی را از سایت یا ZIP خود بسازید.

شماره نسخه اپلیکیشن شما (مثلاً 1.0.0)
Play برای هر بارگذاری عدد بالاتری می‌خواهد؛ خالی بگذارید تا از نام نسخه به‌دست آید.

آنچه می‌توانید به اپلیکیشن تبدیل کنید

هر وب‌سایتی (WordPress، Wix، Shopify، Webflow، Lovable، Bolt، PWA و...)، HTML خودتان، یک فایل HTML یا یک ZIP از سایت ایستا یا بازی HTML5. هر ساخت یک APK رایگان و یک AAB برای Play Store به شما می‌دهد.
