المعلومات الأساسية

سمِّ تطبيقك، ثم اختر ما يعرضه: موقع ويب، أو HTML الخاص بك، أو ZIP لموقعك

سيظهر هذا على الشاشة الرئيسية للمستخدم (30 حرفًا كحد أقصى)
الموقع الذي سيُحمَّل في تطبيقك (يجب أن يبدأ بـ https://)
صفحة واحدة، مع CSS وJavaScript مضمّنين. تُشحن داخل التطبيق وتعمل دون اتصال.
صفحة .html واحدة. لصفحة لها صور أو ملفات CSS أو JS خاصة بها، استخدم ZIP.
ملف ZIP يحتوي على index.html (في المستوى الأعلى، أو داخل مجلد علوي واحد، أو في dist/ أو build/). كل ما فيه يُشحن داخل التطبيق ويعمل دون اتصال. تُرسل ملفاتك إلى خادم الإنشاء لدينا فقط لإنشاء تطبيقك، ولا يتم الاحتفاظ بها.
تطبيق تطوير يعرض خادم التطوير على جهاز الكمبيوتر لديك (Vite وNext.js ...) على العنوان http://localhost:PORT، مع إعادة التحميل الفوري. وصّل الهاتف عبر USB ونفّذ adb reverse tcp:PORT tcp:PORT. للاختبار فقط: أنشئ التطبيق الحقيقي من موقعك أو ZIP.

رقم إصدار تطبيقك (مثل 1.0.0)
يحتاج Play إلى رقم أعلى مع كل رفع؛ اتركه فارغًا لاشتقاقه من اسم الإصدار.

ما يمكنك تحويله إلى تطبيق

أي موقع (WordPress وWix وShopify وWebflow وLovable وBolt وPWA...)، أو HTML الخاص بك، أو ملف HTML، أو ZIP لموقع ثابت أو لعبة HTML5. كل عملية إنشاء تعطيك APK مجانيًا وAAB لـ Play Store.
