نعم. كل عملية إنشاء تعطيك AAB، وهي الصيغة التي يطلبها Google Play، موقّعة وجاهزة للرفع. احتفظ بنفس اسم الحزمة مع كل تحديث.

كيف أحدّث تطبيقًا نشرته بالفعل؟

أنشئ التطبيق مرة أخرى بنفس اسم الحزمة ورقم إصدار أعلى (مثل 1.0.1). تحصل الحزمة نفسها دائمًا على مفتاح التوقيع نفسه، فيُثبَّت الإصدار الجديد كتحديث. للتغييرات دون إصدار جديد، استخدم التحديث عن بُعد.

هل يمكنني إضافة إعلانات وكسب المال؟

نعم. أضف AdMob App ID ومعرّفات وحدات الإعلان: تُدعم إعلانات البانر والبينية والمكافئة والبينية المكافئة والمستطيل المتوسط وفتح التطبيق، وتوضع تلقائيًا أو تتحكم بها صفحتك.

هل يدعم الإشعارات؟

نعم، عبر مشروع Firebase الخاص بك (ارفع google-services.json) أو OneSignal.

هل يمكنني تحويل HTML أو ZIP أو موقع مبني بالذكاء الاصطناعي إلى تطبيق؟

نعم. الصق HTML أو ارفع ملف HTML أو ZIP لموقع مبني (Lovable وBolt وv0 وGoogle AI Studio وVite وبنيات React)، فيُشحن داخل التطبيق ويعمل دون إنترنت.

ما الأذونات التي سيملكها تطبيقي؟

فقط تلك التي تحددها في إعدادات التطبيق. يعلن تطبيقك عن هذه الأذونات بالضبط، فلا يرى Google Play وPlay Protect أي شيء إضافي.

هل تطبيقي آمن للمشاركة؟

نعم. تُنشأ التطبيقات وتُوقَّع على خادمنا؛ ولا تُكشف أدوات الإنشاء ومفاتيح التوقيع في المتصفح أبدًا، ولا يتم الاحتفاظ بملفاتك المرفوعة.
