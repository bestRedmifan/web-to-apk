Información básica

Ponle nombre a tu app y elige qué muestra: un sitio web, tu propio HTML o un ZIP de tu sitio

Esto aparecerá en la pantalla de inicio del usuario (máx. 30 caracteres)
El sitio web que se cargará en tu app (debe empezar por https://)
Una página, con su CSS y JavaScript integrados. Se incluye dentro de la app y funciona sin conexión.
Una sola página .html. Para una página con sus propias imágenes, CSS o archivos JS, usa ZIP.
Un ZIP con un index.html (en la raíz, dentro de una sola carpeta o en dist/ o build/). Todo lo que contiene se incluye dentro de la app y funciona sin conexión. Tus archivos se envían a nuestro servidor de compilación solo para compilar tu app y no se conservan.
Una app de desarrollo que muestra el servidor de desarrollo de tu PC (Vite, Next.js...) como http://localhost:PORT, con recarga en caliente. Conecta el teléfono por USB y ejecuta adb reverse tcp:PORT tcp:PORT. Solo para pruebas: compila la app real a partir de tu sitio o ZIP.

Número de versión de tu app (p. ej., 1.0.0)

Lo que puedes convertir en una app

Cualquier sitio web (WordPress, Wix, Shopify, Webflow, Lovable, Bolt, PWA...), tu propio HTML, un archivo HTML o un ZIP de un sitio estático o juego HTML5. Cada compilación te da un APK gratis y un AAB para Play Store.
