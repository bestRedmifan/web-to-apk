NUESTRA HISTORIA

De la frustración a la solución

Todo empezó cuando necesitamos crear una app de Android sencilla para un negocio local. Tenían un sitio web hermoso, pero querían que sus clientes tuvieran una app.

Exploramos las opciones: contratar a un desarrollador (5,000-20,000 $), usar herramientas de desarrollo complejas (semanas de aprendizaje) o usar conversores existentes (costosas suscripciones mensuales con resultados mediocres).

Ninguna de estas opciones tenía sentido para una simple conversión de sitio web a app. Así que creamos nuestra propia solución.

Lo que empezó como una herramienta interna ganó popularidad rápidamente cuando amigos y colegas pidieron usarla. Nos dimos cuenta de que había una enorme demanda de un conversor de sitio web a APK simple, gratis y rápido.

Hoy, FreeWebToApk atiende a más de 50,000 usuarios en todo el mundo y ha generado más de 100,000 APK. Y apenas estamos comenzando.
