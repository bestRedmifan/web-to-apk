Informazioni di base

Dai un nome alla tua app, poi scegli cosa mostra: un sito web, il tuo HTML o uno ZIP del tuo sito

Apparirà nella schermata home dell'utente (max 30 caratteri)
Il sito web che verrà caricato nella tua app (deve iniziare con https://)
Una pagina, con CSS e JavaScript incorporati. Viene inclusa nell'app e funziona offline.
Una singola pagina .html. Per una pagina con immagini, file CSS o JS propri, usa ZIP.
Uno ZIP con un index.html (in cima, in una cartella principale o in dist/ o build/). Tutto ciò che contiene viene incluso nell'app e funziona offline. I tuoi file vengono inviati al nostro server di build solo per creare la tua app e non vengono conservati.
Un'app di sviluppo che mostra il server di sviluppo del tuo PC (Vite, Next.js...) come http://localhost:PORT, con hot reload. Collega il telefono via USB ed esegui adb reverse tcp:PORT tcp:PORT. Solo per test: crea l'app vera dal tuo sito o dal tuo ZIP.
