    How to use it

    1. Paste your Google Play link (https://play.google.com/store/apps/details?id=your.package) or any link to your app.
    2. Choose colours and size; keep strong contrast between the code and its background.
    3. Download PNG for screens or SVG for print.
    4. Scan the printed result with two different phones before you order a thousand flyers.

    Which link to put in the code

    Use your Play Store link once the app is published: it works for everyone and updates happen automatically. Before publishing, you can point it at a page on your website that explains how to install the APK, so the code keeps working when you switch to the Play link later.

    Questions

    Do these QR codes expire?

    No. The link is stored in the code itself; there is no tracking service in between that could stop working.

    PNG or SVG?

    PNG for websites, slides and social posts. SVG for anything printed, because it stays sharp at any size.

    Can I put my logo in the middle?

    Keep it small and scan-test it. A logo covers part of the code, and too large a logo stops it scanning.
