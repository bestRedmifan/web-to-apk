Основная информация

Назовите приложение, затем выберите, что оно показывает: сайт, ваш HTML или ZIP с вашим сайтом

Это название появится на главном экране пользователя (макс. 30 символов)
Сайт, который будет загружаться в вашем приложении (должен начинаться с https://)
Одна страница, CSS и JavaScript внутри неё. Она встраивается в приложение и работает офлайн.
Одна .html-страница. Для страницы со своими изображениями, CSS или JS-файлами используйте ZIP.
ZIP с index.html (в корне, в одной общей папке или в dist/ либо build/). Всё, что в нём есть, встраивается в приложение и работает офлайн. Ваши файлы отправляются на наш сервер сборки только для создания приложения и не хранятся.
Приложение для разработки, которое показывает dev-сервер вашего ПК (Vite, Next.js...) как http://localhost:PORT, с горячей перезагрузкой. Подключите телефон по USB и выполните adb reverse tcp:PORT tcp:PORT. Только для тестирования: настоящее приложение собирайте из своего сайта или ZIP.

Номер версии вашего приложения (например, 1.0.0)
Play требует более высокий номер при каждой загрузке; оставьте пустым, чтобы вывести его из названия версии.

Что можно превратить в приложение

Любой сайт (WordPress, Wix, Shopify, Webflow, Lovable, Bolt, PWA...), ваш собственный HTML, HTML-файл или ZIP со статическим сайтом или HTML5-игрой. Каждая сборка даёт бесплатные APK и AAB для Play Store.
