Для приложений на WebView: если на вашем сайте есть пользовательский контент, реклама или ссылки на внешние сайты, укажите это в анкете.

📋 Декларации приложения

🔐 Распространенные разрешения приложений

🌐
INTERNET Необходимо для приложений на WebView
📁
WRITE_EXTERNAL_STORAGE Для скачивания файлов
📷
CAMERA Для загрузки фото и видео
🔔
POST_NOTIFICATIONS Для push-уведомлений
⚠️
Важно: запрашивайте только те разрешения, которые приложение действительно использует. Google может отклонить приложения с лишними разрешениями.

Google требует, чтобы новые разработчики провели закрытое тестирование перед публикацией в продакшен.

14 Дней непрерывного тестирования
20+ Страны (откуда тестировщики)
🎯
Где найти тестировщиков:
  • Друзья и семья с телефонами на Android
  • Подписчики в соцсетях
  • Сообщества Reddit (r/androidapps, r/betatester)
  • Группы в Facebook для бета-тестировщиков
  • Посетители вашего сайта
